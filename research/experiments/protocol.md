# Experiment Protocol

## Principles

- Pre-register hypotheses and metrics.
- Use reproducible datasets and seeds.
- Separate behavioural metrics from consciousness claims.
- Report negative results.

## Candidate experiments

1. **Memory continuity:** store experiences, restart, verify retrieval + provenance.
2. **Psychological consistency:** compare trait/emotion trajectories across runs.
3. **Self-model stability:** perturb inputs, measure self-model drift.
4. **Cognitive adaptation:** feedback-driven learning without identity change.
5. **Temporal continuity:** verify paused instances do not accumulate fictional experiences.
6. **Identity reconstruction accuracy:** checkpoint → restore → compare.
7. **Embodied interaction:** avatar change must not alter identity.

## Metrics (engineering, not consciousness)

- Retrieval precision/recall.
- Provenance completeness.
- Identity version integrity.
- State restoration fidelity (hash match).
- Conflict detection rate.
- Consent/authorization test pass rate.

## Forbidden

- Labelling any benchmark as a consciousness detector.
- Claiming consciousness from discussion ability.

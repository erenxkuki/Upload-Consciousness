# Cognitive Architectures

## Overview

Survey of brain-inspired and cognitive architectures relevant to UCC. All are
engineering references, not claims of consciousness.

## Candidate approaches

- **ACT-R / Soar:** Production-rule cognitive architectures; explicit memory
  and goal management. Relevant to planning and working memory modules.
- **Global Workspace implementations:** Shared broadcast layer; relevant to
  attention/context prioritization.
- **Predictive coding networks:** Hierarchical prediction error minimization;
  relevant to belief updating and perception fusion.
- **Memory-augmented neural networks:** External memory; relevant to hippocampus
  module.
- **Multi-agent / society of mind:** Specialized sub-agents; relevant to
  cognitive orchestration.

## Design guidance for UCC

- Keep inference providers replaceable; identity independent of model.
- Prefer explicit, auditable state transitions over opaque end-to-end models.
- Require provenance for any generated conclusion.
- Bound personality drift; never let generated content become verified memory.

## Limitations

- No architecture has demonstrated consciousness.
- Scaling and verification remain open.
- Evaluation metrics for "psychological continuity" are not standardized.
